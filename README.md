# お金の目標

カテゴリ（食費、貯金、旅行資金など）ごとに目標額を決めて、「目標に対していまどこにいるか」を日次・月次で追う、自分用のアプリです（スマホ向け PWA）。家計簿そのものではなく、目標との距離を見るためのものです。

- **目標**: 「上限タイプ」（期間内にいくらまで使うか）と「貯金タイプ」（期間内にいくら貯めるか）。期間は「毎月（月ごとにリセット）」か「期限付き（開始日〜終了日）」。カテゴリごとに色を選べる
- **記録**: 日付・カテゴリ・金額・メモ。トップのカテゴリのチップ（または各カードの＋）をタップ → 金額を入れて「記録する」で、今日の記録がすぐ入る。返金・引き出しはマイナスとして記録。あとから編集・削除できる
- **進捗**: カテゴリごとに「現在額／目標額」・達成率・進捗バー。上限タイプは「残り使える額」と「1日あたり使える額」、貯金タイプは「残り貯める額」と「1日あたり必要な額」。期間の経過割合と比べて「ペース通り／先行／遅れ」を表示（バーの | は今日までの目安）
- **日次**: その日の記録一覧と、カテゴリ別の当日合計（1日の目安つき）
- **月次**: 月ごとのカテゴリ別の実績・達成状況・前月比。過去の月にさかのぼれる
- **設定**: 目標の並べ替え・アーカイブ、テーマ（自動／ライト／ダーク）、バックアップの書き出し・読み込み
- **端末内に保存**: データはその端末のブラウザ内（localStorage）だけに保存され、どこにも送信されません。オフラインでも動きます

## 使い方

ビルド不要の静的サイトです。GitHub Pages で `main` ブランチのルートを公開し、スマホのブラウザで開いて「ホーム画面に追加」してください。

手元で試すとき:

```sh
python3 -m http.server 8000   # http://localhost:8000/ を開く
node --test calc.test.js      # 計算ロジックのテスト
```

## ファイル

| ファイル | 内容 |
|---|---|
| `index.html` | アプリ本体（HTML・CSS・JS） |
| `calc.js` | 進捗の計算（集計期間・達成率・ペース・1日あたり・月次集計）。画面とテストで共用 |
| `calc.test.js` | `calc.js` のテスト（`node --test`） |
| `sw.js` / `manifest.webmanifest` / `icon*` | PWA 用（オフライン対応・ホーム画面アイコン） |
| `docs/DESIGN.md` | 設計メモ（画面構成・配色・データ構造・計算ルール） |

## 計算のきまり

- ペース: 目安額＝目標額×経過割合（今日を含む）。差が目標額の ±5% 以内なら「ペース通り」。貯金タイプは目安より多ければ「先行」、上限タイプは目安より少なく使っていれば「先行」
- 今日より先の日付で入れた記録は、その日が来るまで進捗に数えません
- 目標額を変えると、過去の月の達成状況も新しい目標額で計算し直します

Service Worker はネットワーク優先なので、ファイルを更新しても `sw.js` の `CACHE` の番号を上げる必要はありません。

## 対象外（フェーズ2以降）

銀行口座・クレジットカードとの自動連携、家計簿アプリとのデータ同期、通知リマインド。
