## 3. 画面構成（モバイルファースト、最大幅 760px）

ヘッダー「お金の目標」＋設定ボタン、下にタブ3つ。

1. **目標**（トップ）
   - 集計カード（グラデ）：今日の日付、今日の記録件数と合計、「遅れ」の目標数
   - クイック入力：カテゴリのチップを横スクロールで並べる → タップで金額シート（金額欄に自動フォーカス、日付は今日）→「記録」。**2タップ＋金額入力**
   - 目標カード一覧：色の丸＋名前＋タイプ・期間、進捗バー、`現在額 / 目標額`、達成率、
     残り使える額 or 残り貯める額、ペース（ペース通り／先行／遅れ）、
     上限タイプは「1日あたり使える額」、期限付き貯金は「1日あたり必要な額」。カード右上の＋でも記録できる
   - 目標がないときは「最初の目標をつくる」
2. **日次**：‹ 日付 › のナビ（日付をタップでカレンダー）、カテゴリ別の当日合計（`.brow`）、その日の記録一覧（タップで編集・削除）、「この日に記録」ボタン
3. **月次**：‹ 年月 › のナビ（未来には進めない）、月の合計タイル、カテゴリごとの行（実績、目標、達成率バー、達成／未達／進行中、前月比）、過去の月の一覧（タップで移動）

シート（ボトムシート）：記録の追加・編集、目標の追加・編集、設定（目標の並べ替え・アーカイブ、テーマ、バックアップの書き出し／読み込み）。

## 4. データ構造（localStorage `money-goals.v1`）

```js
{
  v: 1,
  goals: [{
    id, name,
    type: 'limit' | 'save',           // 上限タイプ / 貯金タイプ
    amount,                           // 目標額（円）
    period: 'monthly' | 'range',      // 月次（毎月リセット）/ 期限付き
    start, end,                       // 'YYYY-MM-DD'（range のみ）
    color,                            // '#16a36a' など
    archived: false, createdAt
  }],
  entries: [{ id, date: 'YYYY-MM-DD', goalId, amount, memo, createdAt }],
  theme: 'auto' | 'light' | 'dark'
}
```

- 金額は整数（円）。引き出し・返金はマイナスで保存（入力シートで「使った／返金」「貯めた／引き出した」を切り替え）
- 目標の並び順は `goals` の配列順
- 目標を削除すると記録も消えるので、ふだんは「アーカイブ」（一覧から隠すだけ）を使う

## 5. 計算ルール（`calc.js`、node のテストつき）

- **集計期間**：月次は基準日の月の1日〜末日、期限付きは開始日〜終了日
- **現在額**：期間内の記録の合計。**達成率** = 現在額 ÷ 目標額
- **残り**：上限＝目標額 − 現在額（マイナスなら「超過」）、貯金＝目標額 − 現在額（0 以下で「達成」）
- **経過割合** = 今日までの日数（今日を含む）÷ 期間の日数
- **ペース**：目安額 = 目標額 × 経過割合。差が目標額の ±5% 以内なら「ペース通り」
  - 貯金：現在額が目安より多い→「先行」、少ない→「遅れ」
  - 上限：使った額が目安より少ない→「先行」（余裕あり）、多い→「遅れ」（使いすぎ）
  - 開始前は「開始前」、期間終了後は「達成／未達」
- **1日あたり**：残り日数（今日を含む）で残り額を割る。期限付き貯金は「1日あたり必要な額」、上限タイプは「1日あたり使える額」
- **月次ビュー**：月次の目標は「その月の実績 vs 目標額」で達成判定（終わった月は達成／未達、今月は進行中＋ペース）。期限付きの目標は「その月に動いた額」と「月末時点の累計の達成率」。前月比 = その月の実績 − 前月の実績
